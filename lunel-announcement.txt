🚀 پنل Lunel منتشر شد — کانفیگ با یک کلیک، رایگان forever

خب خب خب 😁
یادتونه گفتم «LuneL coming soon...»؟ اومد ✅

بعد از بهینه‌ساز، ArasClient و SMRules، این دفعه رفتم سراغ چیزی که خودم همیشه لازم داشتم:
یه پنل که کانفیگ آماده بده — بدون سرور، بدون Docker، بدون دست‌کاری دستی.

⚡️ Lunel چیه؟

یه پنل تحت وب که هر کی باهاش یه «اینستنس» شخصی می‌سازه و خودش به‌صورت خودکار
۴ تا کانفیگ آماده بهش میده:

🔹 VLESS (WebSocket)
🔹 Trojan
🔹 Shadowsocks (AEAD)
🔹 VLESS xHTTP — ضد اختلال، مخصوص عبور از فیلترینگ سخت

TLS اتوماتیک، WebSocket تمیز، ALPN درست تنظیم‌شده — همون تنظیمی که
باعث میشه کانفیگ از پشت CDN ها و Gateway ها هم وصل شه 📶

━━━━━━━━━━━━━━━

🎁 چی بهت میده؟

🔸 لینک سابسکریپشن — یه لینک با هر ۴ کانفیگ؛ تو اپ Import from URL بزن، تمام
   (هر ۲۴ ساعت خودش آپدیت میشه)
🔸 QR Code برای هر کانفیگ — اسکن کن، وصل شو
🔸 پنل ادمین کامل — لاگ زنده، اتصال‌های لحظه‌ای، آمار مصرف، ری‌استارت با یه دکمه
🔸 چند اینستنس — یه دونه برای خودت، یکی تست، یکی بده به رفیقت 🤝
🔸 موبایل و دسکتاپ — ریسپانسیو کامل، لاگ‌ها گوشی هم خوانا

💰 قیمت: رایگان. برای همیشه. بدون اشتراک، بدون لیمیت.

━━━━━━━━━━━━━━━

🛠 دیپلوی در ۲ دقیقه (بدون حتی یه خط کد)

1️⃣ ریپو رو Fork کن ⤵️
   github.com/ArasTey/lunel

2️⃣ روی پلتفرم موردنظر یه سرویس از ریپو بساز:
   • Start Command: python main.py
   • پورت: 8080
   (Lucity ، Railway ، Render ، Koyeb — هرکدوم داری همون کافیه)

3️⃣ دامنه بگیر و باز کن — تمام ✅

🔑 ورود پیش‌فرض:
   اکانت: admin
   پسورد: admin
   ⚠️ بعد از اولین ورود از Admin → System پسورد رو عوض کن — پنلته، عمومیه نه!

━━━━━━━━━━━━━━━

📱 گرفتن کانفیگ:

1. Create Instance بزن → اسم بذار → پروتکل اصلی رو انتخاب کن → Deploy
2. صبر کن استاتوس بشه Running (چند ثانیه‌ست)
3. برو تو تب Config:
   • لینک سابسکریپشن رو کپی کن → تو اپ Import from URL
   • یا هر کانفیگ رو جدا کپی کن / QR بگیر
4. تو کلاینت وصل شو — تمام ✅

اپ‌های تست‌شده:
v2rayNG • PattNG • NekoBox • Happ • Streisand • ArasClient 😎

━━━━━━━━━━━━━━━

🔐 نکته امنیتی (مهم):

هر اینستنس یه مسیر اختصاصی با توکن مخفی داره (path=/i/xxxxx/...)
کسی که این URL رو نداشته باشه اصلاً نمی‌تونه به کانفیگ‌هات نزدیک شه.
لینک کانفیگ رو فقط به کسی بده که باید وصل بشه.
و اگه لو رفت: تو پنل دکمه Regenerate هست — همه‌چیز عوض میشه، قدیمی‌ها کور میشن ✅

━━━━━━━━━━━━━━━

⚙️ نکته برای پایداری:

روی پلتفرم، یه Volume به مسیر /data وصل کن — اینطوری اکانت ادمین و
اینستنس‌هات بعد از هر آپدیت پابرجا می‌مونن و پاک نمی‌شن.

━━━━━━━━━━━━━━━

🔧 زیر کاپوت چی داره؟ (برای تکنیکی‌ها)

• هسته ریلی از RVG بازنویسی و امنیت‌سنجی شده — باگ‌های نشست و بافر قدیمی بسته شدن
• معماری Console + Worker + Core — هر اینستنس ایزوله اجرا میشه
• Redis نمی‌خواد، Postgres اختیاریه — به‌صورت پیش‌فرض خودکفاست
• متن‌باز کامل — خودت بخون، خودت بیلد کن، خودت دیپلوی کن
